日拱一卒 · 本地版使用说明
========================

这是什么：一个纯本地的任务配速+工时记录小工具。
数据只存在你自己电脑的这个文件夹里（data\pace.db），不联网、不上传。

怎么用：
1. 电脑需要装过 Python（python.org 下载，安装时勾 Add to PATH）。
2. 双击「启动.bat」或「日拱一卒-本地版」快捷方式，浏览器会自动打开
   http://localhost:18630（重复点击不会再开一个服务，只会打开页面）。
   快捷方式可以右键 →「固定到任务栏」，也可以复制到桌面用，效果一样。
   注意：快捷方式里记的是绝对路径，整个文件夹搬家后会失效——
   搬家后双击一次「生成快捷方式.bat」就会在当前文件夹重新生成一个。
3. 第一次打开会自动弹出「使用引导」，一步步带你看完建项目、加任务、计时、
   日历、统计；以后想重看，点页面顶部的「[引导] 使用引导」即可——它会按你当前
   在哪一页，只讲这一页怎么用，气泡里点「看完整教程」能走一遍全流程。
4. 建项目：项目 = 一个整体目标（如「Q4 审计」「年度体检」），只填名字，
   deadline 可选。留空 deadline 的是持续型项目，安全线按各任务的 due 自己算；
   填了 deadline 就按剩余天数倒推每天该投多少。「仅工作日计算」的项目：deadline
   倒推的剩余天数只数工作日（周末和法定节假日都不算天数），分母变小、每天该投的
   量会变多；非工作日当天这个项目不排必需量（安全线为 0），周末加班照样记工时。
   法定节假日按 2026 年国务院放假安排，含调休补班日（补班的周六日算工作日）。
   「不计工时」的项目不进安全线合计。
5. 加任务：点项目名展开，在项目里加细节任务，填预估分钟和 due。
   预估分钟留空会自动按 45 分钟算；勾旁边的「无预估」则不占安全线和建议量，
   适合先挂着、还没想好怎么估的事。新建和编辑同一套规则：留空=45，无预估只能
   靠勾选表达（编辑原值是无预估的任务，打开时会自动勾上）。
   「重复模式」一个下拉管到底：
   - 每天 / 每个工作日 = 日常，自动出现，当天实例的预估作为基础工时计入安全线；
   - 每周几 / 每月几号 / 每月第几个周几 = 重复实例，勾掉一件自动生成下一件，计入安全线。
   重复任务还能设「提前几天开始」：比如每周四 due、提前 2 天，从周二起这期就进
   今日列表和安全线，日历也从窗口起点投出虚影；填 0 = 仅当天可做（不到那天不出现、
   不占安全线），留空 = 不限（对重复任务按不提前处理，免得天天亮出来太吵）。
   勾了「跳过法定节假日」的重复任务，规则日撞上节假日会顺延到之后第一个工作日。
   任务可填多行「详情」：记录背景、要求、链接和下一步，跟着任务长期保存；复制任务和
   loop 下一件都会继承。任务行的 [详情] 用来展开阅读。它和补工时的备注不同，后者只记录
   这一次做了什么。
   任务行上的「[复制]」是复制：同项目、同预估和 due、连重复配置一起抄一份，改个名就能
   用在下个周期。
   任务行上的「[挂起]」是挂起：发出去等回复、暂时推不动的事点它，任务就退出今日排期、
   日历和建议，也不占安全线；挂起的同时 due 和排期会失效清空（搁置的事没法按日子
   催，留着只会刷出没意义的「逾期」），项目卡里会多出「[挂起] 挂起中」折叠区，
   点「恢复」时重新设一个日期，按新日期归位。日常/重复类任务不能挂起（它们的
   节奏是自动的，不需要等）。
   今日页还有一个「[挂起] 等待回复 / 暂时搁置」折叠块（在下一件推荐下面）：所有挂着的
   任务按挂起天数从多到少列出来，每条标「已挂起 N 天」，挂了 3 天以上的会变橙色。
   修改任务信息不会重置挂起天数；只有恢复后重新挂起才开始新一轮计数。
   折起来的时候摘要行也会提醒有几件该催了——每天扫一眼，别忘了跟进。
   今日页列出的任务都能直接改：电脑上点行尾的编辑图标，手机上行尾的「[更多]」菜单
   点「编辑」（手机屏幕窄，每行只留主按钮，其余都收在 [更多] 里）。
6. 每天：今日页看安全线（今天至少投入多少时间）。默认双轨显示：上面「计划」条
   是今天该投的（浅绿 = 日常·重复预估，浅棕 = 项目推进，竖线 = 安全线 / 日目标），
   下面「实际」条是真投进去的（深绿 / 深棕）；看不惯可在设置「显示」组关掉双轨。
   问候区有两条连续挑战：「日目标」按每日工作目标算，「安全线」按当天实际安全线
   算，两条互不影响，各显示已连续几天、今天是否达标、还差多少。安全线为 0 的
   日子跳过：不加天数，也不中断前后的连续成绩。
   今日任务按「今日必做 / 日常·重复 / 其他今日任务」分组：必做只看 due 今天或
   已逾期的一次性任务，日常和周期重复单列，每组都显示件数和预估合计。
   hero 下方有一行灰色「按实际结算预览」，是观察期的参考数据，不影响任何判定。
   「下一件推荐」标题旁的 [设置] 可设置推荐件数、小额阈值和优先项目。当天份额不足阈值
   的会折进「另有 N 件小额建议」，点开仍能看到；默认 30 分钟，填 0 全部推荐。
   任务本身不足阈值、两天内到期或已逾期的不折。优先项目只在同 due、同任务优先级时
   排前，以上设置都不改安全线、due、排期或工时份额。
   点 [计时] 计时。计时条上「停止计时」只记工时；「完成」= 记工时
   + 把任务勾掉（日常/重复任务会自动生成下一件），做完的事点它一步到位。
   「下一件推荐」每行也有对勾，做完可直接完成，电脑和手机都不用再回清单找。
   忘了计时就点「今日已投入」这行末尾的「补记」，会跳到页面底部的原表单，
   并直接定位到分钟输入框；填完后照常点「记下」。
   每天第一次打开会弹一次「每日鞭策」：今天账上还剩多少、明天已排多少，合起来
   压给明天看；不想看可在设置「显示」组关掉。
7. 日历：把任务从任务池拖到某天就是排期；拖日历上已有的任务会连 due 一起改。
   单击日历条目只打开详情，不会改数据；已排期任务在详情里点「取消排期」才放回池子。
   只有 due、没有排期的条目仅作提醒，不显示取消排期按钮。格子挤不下会折成
   「＋N 更多」，点开看全天条目。
   反过来在编辑里改 due，排期也会自动跟着搬到新日期（主动放回池子的除外）。
   日常/重复任务会以浅色条（[日常]/[重复]）投影出未来要执行的日子。
8. 统计页：看每天各项目投入，点柱子看当天明细（预估 vs 实际）；可切「近 7 / 14 /
   30 天 / 本月 / 今年」（今年按月汇总成柱子）。「每天 · 各项目投入」里每条工时点
   [编辑] 可改分钟和备注、[删除] 可删除（这里的删除不进垃圾桶，删前请确认）。
   明细里任务名前的 [日常] 表示它是日常/重复任务（每天、每周几、每月几号都算）。
   「项目累计投入」点开项目，能看每个 loop 各自的耗时（跟随上面的天数区间）。每条 loop 还有一行校准建议：「预估 45m · 近5次均值
   60m → 建议 60m」，点「采用」一键把预估改成建议值。只看有计时的记录，攒够
   3 次才开口，一次调整到均值；预估 20 分钟以下不校准，偏差超过一半会先提醒
   检查记录。没计时的显示还要攒几天。跨好几天才完成的一期会把这些天的工时合并，
   完成日期仍按勾掉那天归属。
   「[标签] 按标签统计」：任务可以打标签（新建/编辑任务时填「标签」栏，逗号隔开，
   如 qc, 检索），这里按标签汇总「完成 N 件 · 共 Xm · 均次 Zm」。适合那种不
   定时不定量的重复活（比如每来一个 case 做一次 QC）——它们不是固定周期，
   loop 管不了，打个 tag 就能算出这类事平均每件花多久。只算记了工时的完成
   件，跨天投入也完整计入；没计时的和进行中的会另行列出但不进均次，区间跟随
   上面的天数切换。
   同一个标签出现在多个项目时会汇总成一行，点开能按项目拆开对账（同名标签
   在不同项目未必是一类活）；只属一个项目的标签直接把项目名放在行首。
9. 设置就在统计页底部，按「目标 / 记账 / 显示 / 系统」分了四组，每条一句话说明，
   长解释收在 [说明] 里点开看：每日工作目标（小时，默认 8h，决定安全线余量和连续达标
   判定）、新一天起点（默认 7 点，凌晨的工时算前一天；排期和日历投影仍 0 点翻页）、
   「项目-」前缀开关、
   界面皮肤（五套：经典纸面 / 夜间档案 / FIELD OPS / 森林露营 /
   轨道计划，下拉即换，选择只保存在当前这台设备的浏览器里）、
   双轨显示开关（今日页计划/实际两条横条，默认开）、每日鞭策开关（默认开）、
   动态结算开关（默认开：勾掉的日常
   按实际工时降安全线，超预估只挂角标不扩线；关掉回到纯预估老口径）、开机自动启动
   （勾选后登录 Windows 自动起服务并打开页面，不想弹页面就取消勾选）、关闭服务。
   「系统」组还有和数据安全、导出有关的：数据备份——每次启动和每天第一次打开都会
   自动备份一份数据库到 data\backup\ 文件夹。普通备份留最近 7 份；同步或恢复覆盖前的
   重要回滚点另外留 3 份，两类互不挤占。「立即备份」可随时手动留一份；「恢复备份」
   会列出每份的时间和数据条数，选好后明确确认才覆盖当前数据。原备份会保留，覆盖前
   也会自动再留回滚点，选错了还能恢复回来。换电脑可以把整个 backup 文件夹拷走。
   局域网访问开关——默认开，手机才能连同一个 Wi-Fi 访问；关掉后只有这台电脑自己能看。
   改完会明确显示「已保存、待重启」，点旁边的「立即重启」即可生效；如果正准备关闭，
   重启前页面会提醒手机目前仍能连。
   「历史数据导出」用于自己做可视化或交给 agent 分析：可下载真正的 Excel（.xlsx）
   或 JSON，按项目、起止日期筛选，也可包含未分配。日期只筛工时，所选项目的任务
   会完整保留作上下文。Excel 有「说明 / 项目 / 任务 / 工时记录」四张表；JSON 保留
   表间 id 关联。脱敏可只隐去项目名，或连任务名一起替换并清空任务详情和工时备注；
   日期、工时、标签保留，不含还原对照表，也不含令牌、垃圾桶等同步信息。
   另外校准建议的小规矩：预估 20 分钟以下的任务不校准（差几分钟就是百分之几十，
   参考价值不大）；偏差超过一半时，采纳前会提醒你先看看最近记录有没有异常。
10. 删错不怕：删掉的项目和任务先进项目页底部的「垃圾桶」，可以恢复或彻底清空。
    工时记录不会跟着丢。
11. 项目多了可以排序和筛选：电脑端按住卡片左边的「[拖动排序]」拖到想放的位置；
    手机上点开「[设置] 编辑项目信息」用「上移 ▲ / 下移 ▼」；列表上方可按名字筛选。
    编辑项目信息里能改名称、deadline、颜色，也能设仅工作日、不计工时、删除项目。
12. 手机想用：电脑和手机连同一个 Wi-Fi，手机浏览器访问
    http://电脑的局域网IP:18630（IP 用 ipconfig 查；页面顶部也会直接显示这行
    [手机] 地址，照着敲那个更省事）。
    也可以点页头「手机访问」扫码：第一次会打开跳转页，登记当前电脑地址并进入 Pace。
    以后收藏跳转页或「添加到主屏幕」即可；家里、公司各扫一次后，打开跳转页会自动
    寻找能连上的那台。电脑地址变了重新扫码。跳转页只保存访问地址，任务和工时仍只
    存在各电脑本地。弹层里也附有完整说明和跳转页链接。
    默认使用发布者的 GitHub Pages 跳转页，只下载代码、不自己部署也可以直接扫码使用。
    需要完全自托管时，在「统计·设置 → 系统 → 跳转页地址」填自己的完整 http:// 或
    https:// 地址并保存；保存后下次打开二维码就会使用新地址，已有 query 和 hash 会保留。
    这个设置存于本机 SQLite 数据库，重启服务和升级 app.js 都不会清空；留空保存或点
    「恢复默认」即可回到发布者的地址。科技皮肤的页头入口和二维码弹层靠左，
    其余皮肤跟随原页头居中。
13. 局域网同步（两台电脑互传数据）：统计页底部「设置」→「局域网同步」。
    先在「本机设备名」写个方便认的名字（如「公司笔记本」），再在「对端地址」
    填另一台电脑的地址，例如 http://192.168.x.x:18630（端口号跟对方启动时
    用的保持一致；对方页面顶部会显示这个地址）。点「检查对端」能看到两边
    的设备名、版本、最后写入时间和数据条数。
    - 从对端拉取：把对方电脑的数据库完整复制过来，覆盖本机。
    - 推送到对端：把本机数据库完整复制过去，覆盖对方。
    操作前会自动在 data\backup\ 里备份一次原库。如果方向错了（会用旧数据
    覆盖新数据），会弹窗拦住，需要确认后才继续；没确认则什么都不改。
    简单口诀：换电脑前「推一下」，换电脑后「拉一下」。
    注意：同步只传项目、任务、工时记录等本地数据，不跨机合并单条记录，
    而是整库替换；同步前两边各自都有重要回滚点，可在「数据备份」→「恢复备份」还原。
14. 自动更新：统计页底部「设置」→「自动更新」。默认关闭，建议在公司电脑或
    不常改配置的电脑上开启。开启后点「检查更新」会连 GitHub Pages 上的更新源
    （https://c3h18o2.github.io/daily-pace/release），比对本机文件 sha256；
    有新版本时显示「立即更新」。更新前会把旧文件按原目录结构备份到
    data\backup\update-<时间戳>\ 里；app.py 更新后需要点「立即重启生效」
    让新后端跑起来，静态文件刷新页面即可生效。
    更新源地址可在「更新源地址」里改成自部署地址，留空用默认。
    两台电脑在同一个局域网时，也可以点「从对端更新」：对方那台 pace 会把自己
    的代码 serve 在 /release/ 路径下，本机直接拉过来用，不用连 GitHub。
    如果你正在改代码或调试，在程序目录放一个名为 DEV-NO-UPDATE 的空文件，
    自动更新就会被禁用，避免开发中的自己被线上版本覆盖；但开发机仍可给别人当源。

核心概念：
- 安全线 = 今天至少投入多少时间，按各任务的 due 和优先级自动算。
- 日常任务（每天 / 每个工作日）的当天实例预估，会作为基础工时计入安全线。
- 连续挑战两条线：日目标看有没投够每日工作目标，安全线看有没投够当天安全线。
- 换电脑：整个文件夹拷走即可，数据都在里面。

关闭（三选一）：
- 页面里：统计页底部「设置」→「[停止] 关闭服务」；
- 双击「停止.bat」（快捷方式启动的后台服务也能关）；
- 如果是用「启动.bat」开的，直接关掉那个黑色命令行窗口也行。
